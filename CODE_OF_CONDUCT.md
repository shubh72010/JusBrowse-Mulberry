# Code of Conduct

JusBrowse is a small community project. This is the entire policy:

1. **Be decent.** No harassment, hate speech, slurs, or personal attacks — in
   issues, PRs, discussions, or anywhere representing the project.
2. **Assume good faith**, especially across language barriers. Ask what someone
   meant before reacting to how they said it.
3. **No spam.** No crypto pitches, no unsolicited promotion, no AI-generated
   issue floods.
4. **Keep it on-topic.** Bug reports need repro steps, not rants. Feature
   requests need a use case, not demands.

Violations get one warning, then a ban from the project's spaces. Enforcement
is at the maintainers' discretion — report problems by opening a minimal issue
titled "CoC report" with no personal details in the body, and a maintainer
will follow up.

*Inspired by the spirit of the Contributor Covenant, shortened to what a
pre-alpha browser project can actually enforce.*
